# Deluxxe Boutique de Festa

Site de uma página com animações ao rolar a tela. Tudo está em `index.html` (HTML, CSS e JS juntos).

## Como personalizar

1. **Contato**: no fim do `index.html`, procure `CONFIG` e troque WhatsApp e Instagram.
2. **Fotos**: coloque na pasta `img/` com estes nomes (JPG). Enquanto a foto não existir, aparece um desenho rosa no lugar.
   - `logo.jpg` e `hero.jpg` (já estão lá, recortados dos prints do Canva)
   - `sobre-1.jpg`, `sobre-2.jpg`
   - `servico-kits.jpg`, `servico-lembrancas.jpg`, `servico-decoracao.jpg`, `servico-15anos.jpg`, `servico-pegue-monte.jpg`, `servico-papelaria.jpg`
   - `galeria-1.jpg` até `galeria-8.jpg`
   - `aliada-1.jpg`, `aliada-2.jpg`, `aliada-3.jpg`
   - `mascote.jpg` (a personagem na seção Vamos conversar)
3. **Textos**: edite direto no `index.html`.

## Como publicar de graça

- GitHub Pages: Settings > Pages > Branch > salvar.
- Ou arraste a pasta no https://app.netlify.com/drop
