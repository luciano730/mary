# Mary Criativa Decorações

Site de uma página com animações ao rolar a tela. Tudo está em `index.html` (HTML, CSS e JS juntos).

## Como personalizar

1. **Contato**: no fim do `index.html`, procure `CONFIG` e troque WhatsApp, Instagram e cidade.
2. **Fotos**: coloque suas fotos na pasta `img/` com estes nomes (JPG):
   - `sobre-1.jpg`, `sobre-2.jpg`
   - `servico-infantil.jpg`, `servico-casamento.jpg`, `servico-cha.jpg`, `servico-aniversario.jpg`, `servico-pegue-monte.jpg`, `servico-baloes.jpg`
   - `galeria-1.jpg` até `galeria-8.jpg`
   Enquanto a foto não existir, aparece um desenho rosa no lugar.
3. **Textos**: edite direto no `index.html` (números da seção Sobre, depoimentos, serviços).

## Como publicar de graça

- GitHub Pages: Settings > Pages > Branch > salvar.
- Ou arraste a pasta no https://app.netlify.com/drop
